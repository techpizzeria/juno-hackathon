# Creak

Stick to your physio. Feel the difference.

Creak is a playful mobile app that helps people actually keep up with their
physio exercises, with a little cloud named Creaky cheering them on.

## Project summary

Creak is an always-on physio coach helping patients manage rehabilitation with clear, personalised exercise programmes and consistent support between appointments. Its goal is to help patients recover confidently while enabling physiotherapists to deliver efficient, responsive care.

What it does:

- Build a program by chatting with Creaky (AI), or add your own exercises by hand.
- Set reminder times and get local notifications with Done, Snooze, and Skip.
- Log each session, adjust the sets and reps you actually managed, and note any pain.
- Optional form check: record a short video and get quick AI feedback on it.
- Keep a streak. Creaky's mood shifts with your progress: sunny, grey, rainy, or stormy.

Built in Flutter and runs fully on-device. No backend. iOS first, with Android
builds too.
